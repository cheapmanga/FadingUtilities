Mods & Tools

Community mods and external tools to enhance your Fading Echo experience

Mods

ALL THE MODS BELOW NEED UE4SS INSTALLED. If you need help with the installation process or if mods are not working, contact me on Discord: cheapmanga_89714. Note: Do not create mods with UE4SS Debugging Tools (OpenGL 3) - External Thread or it will ask for administrator rights to remove it — and you will not be able to remove it even with them. You will have to remove it using the console.
All Mods & READMEs on GitHub

Teleport Mod

Save your position anywhere, then teleport back instantly. A lightweight alternative to Cheat Engine for practising routes.

Controls

  • F6 : save your position and rotation
  • F7 : teleport back to it
README Download Mod

Volume Mod

See invisible walls, triggers and collision volumes — ideal for route planning and glitch hunting.

Commands

  • show volumes : reveal the invisible geometry
⚠️ Steam wipes it on every launch. This is an Engine.ini, not a Lua mod: you must re-apply it each session with the bundled apply-engine-ini.bat. Full routine in the README.
README Download Mod

Void Cancel Mod

Fall forever — no void, no respawn. Unlike the glitch setup, it doesn't touch your save and you can turn it back off.

Controls

  • F9 : enable the Void Cancel
  • F10 : disable it, restoring void and respawn
⚠️ F10 also opens the UE4SS debug GUI on some builds — the README says how to rebind it.
README Download Mod

HUD Mod

Hide the HUD for clean screenshots and video capture.

Commands

  • hud : show / hide the HUD — run it again to bring it back
README Download Mod

Core Giver Mod

Give yourself elemental cores, useful for exploration and glitch hunting.

Commands

  • core <element> : spawn a core in your hands — water, waste, fire, glitch, power
  • core <element> nograb : drop it in front of you instead
  • core list : list the available elements
README Download Mod

Jojo Mod

Keep the Pipe's flying movement mode. Travel through any Pipe and come out flying — then go anywhere.

Commands

  • jojo on : arm it, then travel through any Pipe
  • jojo off : stop and clean up
README Download Mod

MoonJump Mod

Infinite jump / BotW-style flight.

Controls

  • F3 : MoonJump — hold jump to keep rising
  • F4 : MultiJump — re-jump in mid-air, indefinitely
  • moonjump speed <n> : rise speed (default 700)
README Download Mod

Chest Mod

Teleport from chest to chest across the loaded zone, nearest first.

Commands

  • chest : go to the next chest (the 1st call goes to the nearest)
  • chest prev / chest <n> : go back / jump to the n-th
  • chest list : list the loaded chests and their distance
README Download Mod

KillAll Mod

Kills every enemy currently loaded in the level.

Commands

  • killall : kill every loaded enemy
  • killall count : count them without killing anything
README Download Mod

Source Giver Mod

Give yourself connected sources — they open gates and, at 12, the ending.

Commands

  • source / source <n> : +1 or +n connected sources
  • source set 12 : set the total — 12 opens the ending
  • source status : show the current total
README Download Mod

XP Giver Mod

Give yourself Ætherfact points (skill points).

Commands

  • xp / xp <n> : +1 or +n Ætherfact points
  • xp status : show the balance, granting nothing
README Download Mod

Skins Mod

Access One's hidden skins, swap her whole model, or strip her black outline.

Commands

  • skin one <0-4> : apply a skin — 1 is Hellgur One, 2/3/4 never appear in the menu
  • skin mesh <alias> : swap One's model (skin mesh list for the aliases)
  • skin outline off : remove the character outline
  • skin reset : restore everything
README Download Mod

Game Speed Mod

Slow the whole game down to study a trick frame by frame, or speed it up to skip a stretch you already know.

Commands

  • gamespeed 0.25 : quarter speed — ideal for reading a glitch
  • gamespeed 3 : triple speed
  • gamespeed reset : back to normal
Never during a run: the game slows but your timer doesn't — LiveSplit and the screen will disagree.
README Download Mod

Gravity Mod

Scale the player's gravity — floaty jumps, or none at all.

Commands

  • gravity low : preset 0.3, floaty
  • gravity <n> : any scale (1 = normal, 0 = none)
  • gravity reset : restore the original
README Download Mod

Camera FOV Mod

Widen or narrow the camera's field of view.

Commands

  • fov 120 : set the field of view (10-170)
  • fov lock : keep it, even through camera transitions
  • fov reset : back to the original
README Download Mod

Screenshot Mod

Take a screenshot rendered at up to 8x your screen resolution.

Commands

  • screenshot : capture at 2x
  • screenshot 4 : capture at 4x (1-8)
Files land in %LOCALAPPDATA%\UE_YGRO\Saved\Screenshots\ — captures have no HUD or menus.
README Download Mod

Bad Apple Mod

Play Bad Apple in front of you — the video is rendered live by the game's own cubes!

Commands

  • badapple play ism : start playback (recommended mode, no trailing)
  • badapple pause / resume : freeze and resume
  • badapple stop : stop and clean everything up

Cheat Engine - Practice Tool

Teleportation tool using Cheat Engine for practice and route optimization.

Requirements:

  • Cheat Engine 7.5 or 7.6
  • Download the table file

Installation:

  • Download the table
  • Open the table by double-clicking it
  • Open the game
  • Open the game process in Cheat Engine
  • Check "Auto Assemble script" (Don't forget!)

Controls:

  • Press "C" to save your position
  • Press "X" to teleport
Note: If the teleportation is not immediate, move your character a bit. If you know the coordinates and if you are in the correct dimension, you can just teleport yourself anywhere.
WORK IN PROGRESS: This is currently a work in progress for Fading Echo v. 1.0.27280

Infinite Health/Æther

Make yourself invincible using Cheat Engine for testing and practice purposes.

Step-by-step:

  1. Open Cheat Engine and attach to the game
  2. Set Value Type to "Float"
  3. Set Scan Type to "Unknown initial value" → Click "First Scan"
  4. Take damage in game → Set Scan Type to "Decreased value" → "Next Scan"
  5. Heal → Set Scan Type to "Increased value" → "Next Scan"
  6. Repeat until you have ~90 results or less (it's quick!)
  7. Heal until full HP
  8. Search for values that are 250 (or more if you have perks)
  9. Add them to the address list
  10. Check the active box for all 8 lines
Bravo! You're now invincible. 🎉
