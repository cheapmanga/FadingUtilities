Teleport Mod

v0.1.0

A powerful alternative to Cheat Engine for practicing routes and exploring the game world. Save your position anywhere and teleport back instantly with a single key press.

Controls

  • F6 : save current player position and rotation
  • F7 : load saved player position and rotation
IMPORTANT: The readme is made for the Volume Mod but the Teleport Mod is included.
Note: Do not create mods with UE4SS Debugging Tools (OpenGL 3) - External Thread or else it will ask you administrator rights to remove it. Even if you have them you will not be able to remove them. You will have to remove it using the console.

Cheat Engine - Practice Tool

Teleportation tool using Cheat Engine for practice and route optimization.

Requirements:

  • Cheat Engine 7.5 or 7.6
  • Download the table file

Installation:

  • Download the table
  • Open the table by double-clicking it
  • Open the game
  • Open the game process in Cheat Engine
  • Check "Auto Assemble script" (Don't forget!)

Controls:

  • Press "C" to save your position
  • Press "X" to teleport
Note: If the teleportation is not immediate, move your character a bit. If you know the coordinates and if you are in the correct dimension, you can just teleport yourself anywhere.
WORK IN PROGRESS: This is currently a work in progress for Fading Echo v. 1.0.27280

Infinite Health/Æther

Make yourself invincible using Cheat Engine for testing and practice purposes.

Step-by-step:

  1. Open Cheat Engine and attach to the game
  2. Set Value Type to "Float"
  3. Set Scan Type to "Unknown initial value" → Click "First Scan"
  4. Take damage in game → Set Scan Type to "Decreased value" → "Next Scan"
  5. Heal → Set Scan Type to "Increased value" → "Next Scan"
  6. Repeat until you have ~90 results or less (it's quick!)
  7. Heal until full HP
  8. Search for values that are 250 (or more if you have perks)
  9. Add them to the address list
  10. Check the active box for all 8 lines
Bravo! You're now invincible. 🎉
