Teleport Mod

A lightweight alternative to Cheat Engine for practicing routes and exploring the game world. Save your position and rotation anywhere, then teleport back instantly with a single key press.

Controls

  • F6 : save current player position and rotation
  • F7 : load saved player position and rotation
Note: Only one slot is kept — pressing F6 again overwrites it, and the slot is cleared when the game is closed. Check the README in the .ZIP for a tutorial.

Volume Mod

See invisible walls, triggers and collision volumes in the game world. Perfect for understanding level boundaries and planning optimized routes for speedrunning.

Not a Lua mod: this is an Engine.ini that switches on Unreal's built-in debug-draw / debug view modes, complementing the console that ships with UE4SS. Nothing to compile — the whole thing is one config file.

Features

  • Visualize most invisible walls and collision volumes
  • See trigger zones and interactive areas
  • On-screen debug messages and verbose logging
  • Essential for route planning and optimization

Where it goes

  • Copy Engine.ini into %LOCALAPPDATA%\UE_YGRO\Saved\Config\Windows\
  • The bundled apply-engine-ini.bat does this copy for you
⚠️ Steam wipes it on every launch. The game regenerates this Engine.ini each time it starts, so you must re-apply it every session: launch the game once, then run apply-engine-ini.bat (or copy the file back in). Keeping the master copy + the .bat together in a small backup folder makes it a one double-click job. Full routine in the README.
Tip: Setting the copied Engine.ini to read-only can stop the game overwriting it on some builds — if the debug draw disappears, it got wiped anyway and you're back to re-applying each launch.

Core Giver Mod

Give yourself elemental cores, useful for exploration and glitch hunting.

Commands

  • core water : spawns a water core and puts it in your "hands"
  • core waste : same, waste
  • core fire : same, lava
  • core glitch : same, corruption
  • core power : same, powercore
  • core <element> nograb : places it in front of you without picking it up
  • core list : reminder of the commands
Note: Check the README in the .ZIP for a tutorial.

MoonJump Mod

Infinite jump / BotW-style flight.

Controls & Commands

  • F7 : toggle MoonJump — hold jump to keep rising
  • F6 : toggle MultiJump — re-jump in mid-air, indefinitely
  • moonjump : toggle from the console
  • moonjump speed <n> : rise speed, cm/s (default 700)
  • moonjump key <FKey> : watched key (default SpaceBar; use a Gamepad FKey on pad)
  • moonjump status : current state
Note: Check the README in the .ZIP for a tutorial.

Chest Mod

Teleport yourself to all loaded chests.

Commands

  • chest : teleports to the next chest — the 1st call goes to the nearest one
  • chest reset : rebuilds the route from your current position
  • chest prev : returns to the previous chest
  • chest <n> : jumps directly to the n-th chest in the route
  • chest list : lists the loaded chests with their distance (in meters)
  • chest help : reminder of the commands
Note: Check the README in the .ZIP for a tutorial.

Source Giver Mod

Give yourself connected sources — opens gates and, at 12, the ending.

Commands

  • source : +1 connected source
  • source <n> : +n sources (e.g. source 3)
  • source set <n> : set the total to n (source set 12 opens the ending)
  • source status : show the current total without changing anything
  • source unlocked <n> : +n found sources (the other stat, milestones 1/3/6/9)

Skins Mod

Access One's hidden skins, swap her whole model, or strip the outline.

Commands

  • skin one <0-4> : apply a skin (Skin0 = default, Skin1 = Hellgur One, Skin2/3/4 never shown in the menu)
  • skin mesh <alias> : swap One's model (skin mesh list for the aliases, skin mesh reset to restore)
  • skin outline off / skin outline on : remove or restore the character outline
  • skin reset : restore the original materials
  • skin : reminder of the commands
Note: Check the README in the .ZIP for a tutorial.

Cheat Engine - Practice Tool

Teleportation tool using Cheat Engine for practice and route optimization.

Requirements:

  • Cheat Engine 7.5 or 7.6
  • Download the table file

Installation:

  • Download the table
  • Open the table by double-clicking it
  • Open the game
  • Open the game process in Cheat Engine
  • Check "Auto Assemble script" (Don't forget!)

Controls:

  • Press "C" to save your position
  • Press "X" to teleport
Note: If the teleportation is not immediate, move your character a bit. If you know the coordinates and if you are in the correct dimension, you can just teleport yourself anywhere.

Infinite Health/Æther

Make yourself invincible using Cheat Engine for testing and practice purposes.

Step-by-step:

  1. Open Cheat Engine and attach to the game
  2. Set Value Type to "Float"
  3. Set Scan Type to "Unknown initial value" → Click "First Scan"
  4. Take damage in game → Set Scan Type to "Decreased value" → "Next Scan"
  5. Heal → Set Scan Type to "Increased value" → "Next Scan"
  6. Repeat until you have ~90 results or less (it's quick!)
  7. Heal until full HP
  8. Search for values that are 250 (or more if you have perks)
  9. Add them to the address list
  10. Check the active box for all 8 lines
Bravo! You're now invincible. 🎉
