How it works

History before 18 July 2026 comes from a SteamDB export. Since then, an automated task queries the Steam API every 10 minutes and records the changes here.

Known limitation: Steam's public API does not return the depots section for this game (it requires a token that only a Steam account has). When a build is pushed, the tracker detects it through the changenumber but cannot read its buildid. Those entries are marked BUILDS with the note content not public; the details remain available on SteamDB.
